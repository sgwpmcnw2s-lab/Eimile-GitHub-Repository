# 使用手册

## AI更新迭代

查看AI公司官方发布、模型和产品更新，以及GitHub开源AI项目。热度分用于排序，不代表产品质量。点击卡片可查看中英文摘要、原文和手动生成AI分析。

## 海外AI课程

课程范围包括免费和付费录播课，以及具备教师、固定课表和正式报名入口的直播课。训练营、单次Webinar、工作坊和同期班不计入直播课口径。

主要服务人群按优先级为：

1. 零基础个人
2. 职场办公人群
3. 内容创作者
4. 企业管理者

点击“生成本周报告”可以立即生成课程机会报告。插件也会在周五22:00自动生成；检测到主题热度显著上升时生成专项报告。

## AI新闻播报

- “已确认”：官方来源，或至少两个独立可信来源佐证。
- “待验证”：当前只有单一非官方来源。

待验证内容不会触发高优先级重大新闻通知。建议对重要决策始终打开原文核查。

## 我的资料库

卡片右上角支持：

- 收藏：长期保留。
- 已读/未读：管理阅读状态。
- 稍后阅读：加入处理队列并长期保留。
- 添加笔记：保存个人判断、选题灵感和后续动作。

## 搜索和筛选

可搜索中文标题、英文标题、摘要、来源和主题，并按主题、来源、可信状态、已读状态、热度和重要程度组合筛选。

## 报告导出

- Markdown：下载中文结构化报告。
- CSV：下载带UTF-8 BOM的中文表格，可直接用Excel打开。
- PDF：打开中文打印版，选择系统打印窗口中的“存储为PDF”。

## API预算

默认月预算是人民币10元。预算显示为按官方美元Token价格和固定汇率假设计算的估算值，最终账单以DeepSeek平台为准。接近预算时看板会显示橙色，达到预算后停止新的AI分析，但仍继续抓取和展示公开信息。

## 更新和补抓

- Chrome运行时每2小时检查一次。
- Chrome关闭期间不会运行。
- 重新打开后会同步最新公开信息；普通数据最多保留30天。
- 已处理URL不会重复调用AI，内容发生明显变化时可能重新分析。

## 通知

- 21:00至次日09:00不弹出桌面通知。
- 免打扰期间继续收集，09:00生成汇总提醒。
- 重大提醒默认只针对已确认内容。
