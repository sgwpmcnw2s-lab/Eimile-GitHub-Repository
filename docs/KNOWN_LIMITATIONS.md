# 已知限制

1. Chrome未运行或Mac休眠时无法抓取、生成报告或通知。
2. “实时”按已确认口径实现为每2小时同步，不是分钟级推送。
3. Reddit、RSS、GitHub和其他公开接口可能限流、改变结构或暂时拒绝访问。
4. 课程平台公开字段不一致，热度分无法代表真实销量或报名人数。
5. 新闻标题聚类是启发式算法，可能无法识别措辞差异很大的同一事件。
6. DeepSeek费用是本地估算，最终费用以DeepSeek账单为准。
7. PDF导出使用系统打印窗口，需要手动选择“存储为PDF”。
8. API Key采用普通Chrome本地存储，不等同于钥匙串加密。
9. Obsidian同步和163邮箱自动发送属于第二阶段，不在MVP中。
10. 全球语言内容的中文与英文转换依赖DeepSeek；未调用AI的普通内容先显示原始语言。
