# 安装与升级说明

## 一、安装 Chrome 插件

1. 将整个项目文件夹保存在一个不会随意移动的位置。
2. 在 Chrome 打开 `chrome://extensions`。
3. 启用“开发者模式”。
4. 点击“加载已解压的扩展程序”。
5. 选择包含 `manifest.json` 的项目根目录。
6. 在扩展菜单中固定“AI 全球情报雷达”。

插件会申请以下权限：

- `storage`：保存设置、资讯、收藏、笔记和报告。
- `alarms`：每2小时同步、每天09:00汇总、周五22:00生成报告。
- `notifications`：发送重大且已确认的情报提醒。
- `downloads`：导出Markdown和CSV。
- `tabs`：点击插件图标后打开或聚焦完整看板。
- 公开来源域名：只用于抓取已列明的信息源及调用DeepSeek API。

## 二、配置 DeepSeek

1. 登录 DeepSeek 开放平台并确认API余额可用。
2. 在插件中打开“设置”。
3. 将API Key粘贴到“DeepSeek API Key”。
4. 保留默认模型 `deepseek-v4-flash`。
5. 将月预算设为10元或你的实际上限。
6. 点击“保存设置”，然后点击“测试连接”。

不要把API Key写入源代码、截图、文档或GitHub Issue。

## 三、首次同步

1. 点击左下角“立即更新”。
2. 等待来源依次完成；首次同步可能需要几十秒。
3. 在“设置 → 数据来源状态”查看成功条数或异常状态。
4. 网络不可访问或限流的来源会在下一轮同步重试。

## 四、升级

1. 获取仓库的最新版本。
2. 回到 `chrome://extensions`。
3. 找到本插件并点击刷新图标。
4. 打开看板确认版本功能。

升级前不要删除扩展，否则Chrome本地存储的数据可能丢失。重要报告应先导出。

## 五、卸载

在 `chrome://extensions` 点击“移除”。卸载会删除插件的本地存储数据，请先导出需要保留的报告和笔记。
