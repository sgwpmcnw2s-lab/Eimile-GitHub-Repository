# 隐私与数据安全说明

## 本地保存的数据

插件使用Chrome本地扩展存储保存：

- DeepSeek API Key
- 用户设置和重点关注清单
- 最近30天公开资讯
- 收藏、已读、稍后阅读和个人笔记
- AI分析结果、课程报告和估算用量

MVP不使用自建云端后台，也不会把上述本地数据同步到现有Obsidian库。

## 发送给第三方的数据

只有执行DeepSeek分析时，当前资讯标题、公开摘要和分析提示会发送至DeepSeek API。原文链接所指向的网站会在抓取时收到常规网络请求。

## API Key风险

API Key使用普通Chrome本地存储，适用于个人可信设备，但不是macOS钥匙串级别的加密。拥有本机账号和Chrome扩展调试权限的人可能读取该Key。请勿在公用电脑使用，并在疑似泄露时立即到DeepSeek平台撤销。

## 删除数据

- 普通内容在超过保留时间后清理。
- 收藏、笔记、稍后阅读和重大已确认内容需由用户取消状态后才会按规则清理。
- 卸载扩展会删除Chrome为该扩展保存的本地数据。
